# Bangkok Dental Care — website

Static one-page site (`index.html`, `styles.css`, `script.js`). No build step — deploy the folder as-is (e.g. Vercel, Framework Preset "Other").

## Design
Built from the clinic's own branding: the gold crescent-moon-and-tooth logo with sparkles, the burnt-orange hanging sign and orange dental chairs, chocolate-brown wordmark and cream marble walls. Fonts: Fraunces (soft), Figtree, Mitr (Thai).

Sections: hero, clinic standards, treatments (featured implant & crown prices), specialist dentists, the clinic (photos + visit steps), Google reviews, booking form, directions & map.
