# Bangkok Dental Care — website

Static one-page site (`index.html`, `styles.css`, `script.js`). No build step — open `index.html` or serve the folder.

Design: "upstairs from the movies" — the clinic sits in Century the Movie Plaza 2, so the page borrows cinema-ticket motifs (admit-one hero ticket, box-office booking form that prints a live ticket) on porcelain paper with jade ink and marigold accents. Fonts: Gloock, Hanken Grotesk, Anuphan (Thai), JetBrains Mono.
